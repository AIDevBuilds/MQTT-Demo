# MQTT Demo (React Native)

React Native demo that connects to an MQTT broker over WebSockets.

## What it contains

- `src/core/services/MqttService.js`: a singleton wrapper around the Paho MQTT client (connect, connection lost, message arrived)
- `src/core/components/OfflineNotification.js`: a banner for when the connection is lost
- `App.js`: connects and shows the connection state and messages

## Stack

React Native 0.61.3, React 16.9, Paho MQTT.

## Run

```sh
npm install
npx react-native run-android   # or run-ios
```

## Notes

The broker address in `MqttService.js` (`ws://iot.eclipse.org:80/ws`) is an old public test broker address that may no
longer be online. Replace it with your own broker's WebSocket URL.
